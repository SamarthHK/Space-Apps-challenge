# Space-Apps-challenge
The Hollows to the Nasa Space Apps Challenge

## Frontend/backend merger plan

The `merger` branch contains planning documents only. Application code has not
been merged or implemented. AI-model training, inference, and recommendation
implementation are outside this integration milestone.

Read the documents in this order:

1. [Audit and implementation inconsistencies](docs/merger/01-audit.md)
2. [Target architecture and Git consolidation](docs/merger/02-architecture.md)
3. [Shared API and data contract](docs/merger/03-contract.md)
4. [Dependency-ordered implementation plan](docs/merger/04-delivery-plan.md)
5. [Acceptance and release checklist](docs/merger/05-acceptance.md)
6. [Decisions, blockers, and handoff](docs/merger/06-decisions.md)

The audit uses the local frontend/backend checkouts and records their exact
commits, uncommitted documentation, and the separate original checkout in the
first document. Proposed routes and commands are not claims of working services.
